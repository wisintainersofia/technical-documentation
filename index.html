Introduction to Flexbox

The Flexible Box Layout, commonly known as Flexbox, is a CSS3 web layout model.

It provides a more efficient way to lay out, align, and distribute space among items in a container.

display: flex;
  • One-dimensional layout model
  • Improves responsiveness
Flex Container

To start using Flexbox, you need to define a flex container.

Any parent element can be turned into a flex container by setting its display property.

.container { display: flex; }
  • Acts as the parent wrapper
Flex Items

Children elements directly inside a flex container automatically become flex items.

They can be manipulated using various flex properties like flex-grow and flex-shrink.

flex: 1;
  • Direct children of the container
Align Items

The align-items property sets the align self value on all direct children as a group.

It aligns items along the cross axis of the flex container.

align-items: center;
  • Aligns along cross-axis
Media Queries

Media queries are a key part of responsive web design in CSS.

They allow you to apply CSS styles depending on device characteristics like width.

@media (max-width: 768px) { ... }
  • Ensures mobile responsiveness
